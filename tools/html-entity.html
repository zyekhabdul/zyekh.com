Tentang Pengodean Karakter HTML Entities

HTML Entities mengganti karakter berisiko (seperti <, >, &, ") menjadi urutan karakter yang aman untuk ditampilkan oleh peramban tanpa memicu eksekusi kode markup atau kerentanan XSS (Cross-Site Scripting).

Pertanyaan Umum (FAQ)

Mengapa karakter < dan > harus di-encode?

Karena karakter tersebut digunakan oleh parser HTML untuk mengurai elemen tag. Meng-encode-nya menjadi &lt; dan &gt; memastikan teks ditampilkan sebagai string literal.
