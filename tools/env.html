.env to JSON & Secret Redactor

Convert environment variables (.env) to JSON objects or mask secret keys (redact API credentials) 100% offline.

Tentang Konversi .env & Sensor Kunci Rahasia

Berkas .env menyimpan variabel lingkungan dan kredensial sensitif aplikasi. Fitur sensor otomatis (*Secret Redactor*) mendeteksi kata kunci seperti KEY, SECRET, PASSWORD, TOKEN, dan menggantinya dengan nilai sensor agar aman saat Anda ingin membagikan log debug ke forum atau rekan tim.

Pertanyaan Umum (FAQ)

Apakah berkas .env saya dikirim ke server luar?

Sama sekali tidak. Proses konversi dan sensor kunci dilakukan 100% di browser lokal Anda tanpa jaringan backend.
