Tentang Tanda Tangan HMAC (Hash-based Message Authentication Code)

HMAC adalah mekanisme otentikasi pesan menggunakan fungsi hash kriptografi yang dikombinasikan dengan kunci rahasia bersama (shared secret key). Banyak digunakan pada verifikasi Webhook (GitHub, Stripe, Xendit), otentikasi API AWS, dan verifikasi integritas data transaksi.

Pertanyaan Umum (FAQ)

Apakah kunci rahasia HMAC saya dikirim ke server?

Sama sekali tidak. Proses signing HMAC dijalankan 100% lokal di browser Anda menggunakan Web Crypto API (crypto.subtle.sign).
