Tentang Kriptografi Hash & Checksum

Fungsi hash kriptografi adalah algoritma matematika yang memetakan data berukuran acak menjadi string berukuran tetap (digest). Digunakan secara luas untuk memverifikasi integritas berkas, menyimpan kata sandi aman, dan pembuatan tanda tangan digital.
