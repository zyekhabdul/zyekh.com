Pertanyaan Umum (FAQ)

Apakah kunci privat saya disimpan atau dikirim ke internet?

Tidak. Seluruh komputasi kunci dilakukan murni pada memori browser Anda via Web Crypto API. Setelah tab browser ditutup, kunci hilang secara otomatis.

Kapan saya sebaiknya menggunakan Ed25519 vs RSA?

Ed25519 menawarkan performa tinggi, ukuran kunci ringkas (32-byte public key), dan keamanan setara RSA 3072-bit dengan resistensi terhadap serangan side-channel. RSA disarankan jika Anda membutuhkan kompatibilitas dengan sistem warisan (legacy).
