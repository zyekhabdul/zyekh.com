## WORKFLOW INSTRUCTIONS AFTER IMAGE GENERATION

1. Generate images using Midjourney, DALL-E 3, Gemini, or Stable Diffusion.
2. Save both `.jpg` and `.webp` versions into `assets/img/` matching the target filename above.
3. Compress images to under 100 KB using `cwebp` or Pillow.
4. Update `batch_data.json` if target image names are modified.
5. Run the master pipeline to publish clean and purge CDN cache:
   ```bash
   python3 run_pipeline.py --deploy
   ```
