1. Deploying Production Jails via jail.local

Never modify /etc/fail2ban/jail.conf directly, as package upgrades will overwrite changes. Create /etc/fail2ban/jail.local to specify custom thresholds.

# /etc/fail2ban/jail.local
[DEFAULT]
bantime  = 1h
findtime = 10m
maxretry = 5
banaction = ufw

[sshd]
enabled = true
port    = ssh
logpath = %(sshd_log)s
backend = %(sshd_backend)s

Frequently Asked Questions (FAQ)

How do I unban an IP address locked out by Fail2ban?

Execute fail2ban-client set sshd unbanip to remove the ban rule immediately.
